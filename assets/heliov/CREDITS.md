# HelioV voxel texture reference

The voxel face atlases are design-time renders of models from **KayKit: Block
Bits 1.0**, created by Kay Lousberg and distributed under CC0. The original
pack and its license are retained in `kitkat/`.

`kitkat/voxel_faces/README.md` defines the fixed eight-material palette and the
single `[top | side | bottom]` image layout used by the demo.
